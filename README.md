# Population Health Risk Analytics

## Overview

This project analyzes health assessment data to identify risk patterns, population trends, and preventive healthcare opportunities.

## Business Problem

Organizations need population-level health insights to support wellness initiatives and preventive healthcare programs.

## Objectives

- Categorize health risks
- Analyze population trends
- Generate actionable insights
- Support preventive healthcare strategies

## Tech Stack

- SQL
- Python
- Pandas
- Data Visualization
